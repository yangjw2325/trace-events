# AI 使用与验证记录

记录日期：2026-11-02。区分开发协作与产品运行，不把模型自述作为验收证据。

## 开发协作与候选人决策

| 环节 | AI辅助完成 | 候选人作出的决策与审阅 |
| --- | --- | --- |
| 需求与路径 | 对照原题，整理搜索、事件演化、证据、关注路径 | 确定最小MVP；不加入UGC消息；关注分公司与事件；自动更新以每日09:00为目标 |
| 原型与交互 | 制作HTML原型并逐轮修订 | 确认联想只补全、公司／事件分搜、相关性／日期排序、返回来源、主页两栏、标题与时间展示 |
| 证据阅读 | 提出摘要、分类说法、按需引用分层并实现 | 指出事实与总结重复，确认简短概览、独立原文入口、测试账号登录及具体事件已读规则 |
| 数据与实现 | 接入API、解析原文、代码实现、部署与回归 | 提供账号和服务端凭证、完成必要授权、确认方案与上线 |

AI协作工具：Codex。产品运行模型：DeepSeek。未保留每次开发对话的完整可复现实验条件，因此不声称所有代码一次生成通过；用户审阅与多轮修订是交付过程的一部分。

## 产品内模型流程与程序校验

阶段A输入当前文档的提取文本与行／段标识，输出分类说法及逐字引用。程序核对引用确实属于指定文档版本、是对应文本的连续子串，并限制说法类型。

阶段B输入当前说法及已入库候选事件，输出归并、新建、重要变化或待核验决定；更正必须有可定位目标。程序校验目标、依据与当前版本，使用事务写入判断、关系和通知。无重要变化仅补充证据。两阶段提示词及校验实现见`app/lib/ingestion/analyze.js`；发布与并发控制见`app/lib/ingestion/publish.js`。程序没有单独训练一个事实裁判模型。

## 真实资料验证

| 案例 | 验证内容 | 证据与结果 |
| --- | --- | --- |
| 海尔生物吸收合并上海莱士 | 同一事项、多公司、筹划→进展→终止 | 三份PDF按历史顺序进入模型；保持同一事件、形成两个判断版本，进展只补证据，终止触发重要变化；后来的材料不进入早期输入 |
| 贵广网络年度更正 | 区分更正与进展、定位原公告及原字段 | 原风险公告与更正公告匹配；年度2025→2024，金额不因年度更正而改变 |
| 贵广网络传闻否认 | 区分公告事实与被转述传闻 | 保留具体否认范围；未找到传闻首发，不将公司公告的转述冒充传闻原文 |
| 海尔终止后的一个月承诺 | 时间精度与期限边界 | 2025-02-06在期内、02-08超过一个月；02-07保留边界说明。期满不代表合并恢复。此项为样本规则验证 |

原始验证报告随提交包附于`docs/验证结果/`。它们记录当时选定样本的结果，不代表对全部线上事件逐条人工审计。

## 发现的问题与修正

- iFinD业务成功码与扶摇不同，且返回可多层嵌套；接入分别解析业务错误、备注、空结果和实际材料，不能把通信成功当作取数成功。
- PDF将公司名称拆行后，模型自行补字导致引用不匹配，程序拦截发布；调整提示后重新提取。未放宽为模糊引用。
- 模型输出被token上限截断，JSON解析失败；检测截断并调整输出预算，失败不覆盖成功版本。
- 初始摘要与引证重复；正式版改为短概览、分类说法、逐条展开引用，历史完整判断继续留存。
- 未读状态曾容易与历史版本数量混淆；正式版以实际通知及关注起点计算，并测试并发响应不复活已读提示。

## 尚需人工判断的部分

程序校验不能证明每条观点正确、两家公司具有经济因果关系或检索已完整覆盖。语义归并不明确、原文不完整或关键依据缺失时保留待核验。权威公告可以纠正具体字段，但不能推导为“以后不可能出现其他交易”。AI与测试均不构成投资建议。
